변환 기준
· 주차 = 구글시트(FAC1) 기준 수~화 주차. 날짜로 다시 계산합니다. FAC2 원본 WEEK38(9/16~9/22)은 시트 기준 W39라서 한 주 차이가 납니다. 원본 표기는 「원본주차」 열에 그대로 둡니다.
· 설비명 = MC3 → MC03으로 두 자리 통일 (FAC1 DC08 표기와 같은 방식).
· 불량수량 = 원본 defective total = CODE DEFECT(NG) 1~50 합계. 품질(Q) = 양품 ÷ 생산 (행 단위).
· 불량 계통 (Search_Detail_MCT 기준) : 1~16 다캐불량(FAC1 유래) · 17~46 가공불량(FAC2 MCT) · 47~49 협력사 · 50 고객.
· Mat'l NG(MCT 가공 전 소재 불량)와 FG QC Sorting(선별)은 불량수량에 포함하지 않고 별도 열로 둡니다. 원본 KPI MCT와 같은 방식입니다.
· 실제수율 = Σ생산 ÷ UPD(95%) — 설비·일자·품번 단위. 원본 actual yield와 같은 식입니다. 일별 탭은 설비·일자 안에서 품번별 값을 더합니다(품번이 바뀐 날도 합산 가능).
· 원본에 가동/정지시간이 없어서 가동률(A)은 만들지 않습니다. 원본 비고(예: Electric error)는 「비고」 열에 그대로 둡니다.
